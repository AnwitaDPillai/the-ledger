# The Ledger

An interactive archive of effort.

The Ledger is a data visualization of every competition, fellowship, application, and program I've submitted to since 2024 (including some of my older works since 2017) — wins, losses, pending results, and the ones that went quiet. It tracks ~100 entries across the years, rendered as a scroll-driven mountain range: wins as peaks, losses as valleys, pending results as stars still in flight.

Built with vanilla JavaScript, GSAP ScrollTrigger, and Lenis. The data lives in a single file (`data.js`), so the whole visualization updates when I add a new entry.

**Live:** [Link](https://anwitadpillai.github.io/the-ledger/)
